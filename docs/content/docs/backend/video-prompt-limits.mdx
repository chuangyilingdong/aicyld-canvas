description: 按实际接入接口和模型校验长度，区分字符、UTF-16 和 token

## 规则

视频没有统一的 8000 或 32000 字符限制。默认值按协议和模型选取，用户已保存的能力配置或渠道目录中的明确值优先。`promptMaxChars: 0` 表示本地没有字符上限，由服务商继续校验，不能理解为服务商无限接收。系统不自动截断提示词。

字符数按 Unicode 码点统计；明确使用 UTF-16 的接口另存 `promptMaxUtf16Units`，前后端统一计数，常见表情占两个单位。Veo 的 token 上限不换算成字符数，交由上游校验。图片与文本模型的既有限制不受视频调整影响。

## 本地零上限

以下路径没有公布可直接采用的字符硬上限，本地默认值为 0，不继续使用通用 8000：

- Ark Seedance 系列
- `newapi` / `newapi-channel-2` 下的 Seedance 标准、Fast、Mini
- Kling、Grok、Agnes 视频
- Gemini Veo（token 限制交由上游）
- 未知自定义渠道和不匹配的工作流

未知或新增模型 ID 不通过前缀猜测限制。真实生成成功只证明该请求被执行；允许更长提示词不保证人物对应、台词、构图等全部遵循。

旧配置中的 8000 可能来自历史默认，也可能是用户主动设置，不能仅凭数值猜测并覆盖。保存的能力配置优先；如需恢复接口默认值，在模型能力设置中点击“恢复默认限制”。
